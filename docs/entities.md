# transform/entities.py — 実体タグ付け規則(loop_003)

## タグ付け規則(F-03)

1. **辞書**: data/curated/entities.csv のみ(AGENTS §2)。名称(括弧部除去)+aliases が照合表層
2. **最長一致**: 長い表層形が消費した範囲は短い表層形に使わない
   (「薬師寺」内の「薬師」、「香薬師」内の「薬師」を誤タグしない)
3. **文脈規則(ctx=)**: notes の `ctx=語1|語2` に列挙された別名は、親実体(parent 列)の
   名称が同一段落または直前 3 段落(CONTEXT_WINDOW)に出現する場合のみ有効
4. **曖昧は保留**: 同一表層で複数実体が同時成立(例: 両親寺文脈下の「十一面観音」)なら
   タグ付けせず needs_review(ambiguous_ctx)へ(捏造禁止 — 迷ったら保留)
5. **未知候補**: 辞書外の寺名らしき語(漢字 1–6+寺/院)は needs_review(unknown_temple)へ。
   タグは付けない。実行: `python -m transform.entities` → out/needs_entity_review.csv

## gold 注釈規約(2026-07-23 ユーザ承認)

- **別名限定主義**: 辞書の名称・別名による言及のみを gold とする。指示語・未登録の
  同一指示(「夢殿の秘仏」=救世観音、「思惟像」等)は含めない
- **係り先明示**: 「聖林寺の十一面観音」のように係り先が明示された言及は、
  両親寺文脈でも gold に含める(タガーは保留するため、再現率は真の下限を測る)
- **鑑真規約 B**: 実体「鑑真和上」は人物言及・像言及を一実体として扱う
